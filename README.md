# Rua das Vitrines

Catálogo de landing pages construídas para microempreendedores — comércio local, profissionais autônomas, ferramentas de captação de contato e direção de arte.

- `/` — página índice (a vitrine)
- `/barbearia`, `/petshop`, `/estetica-automotiva`, `/almoco-ja`, `/fotografa`, `/vet-camila-duarte`, `/calculadora-leilao`, `/portfolio-topolski` — cada landing page publicada, pronta pra abrir direto pelo link.

Site estático, sem build necessário — pronto pra publicar no Vercel.
